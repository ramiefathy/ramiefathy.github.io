🚀 Welcome to Enhanced UI Features

This page demonstrates the new UI enhancements for the AI Dermatology Scribe application. Try out the features below to see how they improve the user experience.

🎨 Theme Switcher

Click the theme toggle button in the bottom-right corner to switch between light, dark, and auto themes.

⚡ Quick Actions Bar

A floating toolbar with common actions. Drag it anywhere on the screen!

🔍 Command Palette

Press Ctrl+K or Cmd+K to open the command palette.

🎯 Focus Mode

Press Ctrl+Shift+F to enter distraction-free focus mode.

♿ Accessibility

Enhanced keyboard navigation, screen reader support, and high contrast mode.

📐 Layout Manager

Switch between different layout presets using the dropdown in the header.

⌨️ Keyboard Shortcuts

Master these shortcuts for maximum efficiency:

Action Shortcut Description
Command Palette Ctrl/Cmd + K Open command palette for quick actions
Focus Mode Ctrl + Shift + F Toggle distraction-free mode
Capture Image Ctrl + I Open image upload dialog
Add Diagnosis Ctrl + D Quick add diagnosis
Order Labs Ctrl + L Open lab order panel
Prescribe Ctrl + P Open prescription dialog
Schedule Follow-up Ctrl + F Schedule next appointment
Start Recording Alt + R Begin voice recording
Focus Transcription Alt + 1 Jump to transcription panel
Focus Notes Alt + 2 Jump to notes panel
