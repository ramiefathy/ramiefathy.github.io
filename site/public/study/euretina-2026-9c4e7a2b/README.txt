EURETINA 2026 STUDY GUIDE — WEBSITE EXPORT
Snapshot: 7 October 2026, published version 2.

QUICK START
Unzip this package. Upload index.html and the assets folder together into a
folder on your website, for example /euretina/. Open that folder's URL.
Keep the assets folder next to index.html; all image paths are relative.
No build step, package installation, backend, database, or API key is needed.
The page also opens locally by double-clicking index.html.

The companion EURETINA-2026-Study-Guide-Standalone.html embeds all four images,
styles, code, and guide content in one file. You can upload it alone and rename
it index.html. It opens offline in a modern browser with JavaScript enabled.
In the standalone version, click a figure to open a full-size dialog; use its
scrollbars if needed, then Close figure or Escape to return.

If your host applies a Content Security Policy, allow this page's inline
JavaScript and styles and its local/data images, or adapt it to your policy.
CMS editors often strip script tags: upload the file as a standalone page
rather than pasting its source into a visual editor. A same-site iframe can
embed the hosted page in an existing layout; allowfullscreen enables the
presentation's full-screen control.

WHAT IS INCLUDED
- Reading view, search and coverage/type filters
- Click-through presentation, keyboard/swipe navigation, and full-screen control
- 10 full-session entries: 9 reviewed, plus the clearly unavailable Valeda recording
- 76 chapter summaries
- 69 individually starred talks/posters: 51 ready, 18 still pending

This is a fixed snapshot. The pending items remain pending; the export does
not fetch updates or mark unreviewed material as complete. Original summaries,
limitations, timestamps, source references, and screenshot attributions are
preserved. The original private Site has not been changed by this export.

SOURCES AND ACCESS
The guide itself and its images work offline. Official programme links need
an internet connection and may require the viewer's own conference login.
No conference recordings, signed recording URLs, login credentials, API keys,
private download links, or session tokens are included.

These static files do not include password protection or the private Site's
access controls. If you upload them to a public website, their entire content,
including your starred-programme selection, will be public. Use your host's
own access controls if you want to limit readership.
